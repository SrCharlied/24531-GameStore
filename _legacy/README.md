# Legacy (Blade)

Esta carpeta archiva la versión Blade del proyecto, antes de migrar a la
arquitectura React + REST API. Nada de aquí se ejecuta — Laravel ya no carga
estos archivos porque las rutas `web.php` fueron limpiadas y los controllers
viejos no están en `app/Http/Controllers/`.

Se mantiene como referencia histórica. Si necesitas restaurar alguna pieza,
los archivos siguen siendo PHP válidos y se pueden mover de vuelta a su
ubicación original.
